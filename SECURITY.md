# Security policy

`docker-lease` stops and deletes Docker containers on your machine, so a bug here can destroy work. Please report problems privately.

**Do not open a public issue for a vulnerability.**

Preferred: use this repository's private vulnerability reporting, under the Security tab ("Report a vulnerability"). If it is not available, use the fallback below, which reaches the same maintainer.

Fallback: report via GitHub Security Advisories private contact.

A useful report includes the commit or version, your macOS version, the smallest reproducer that shows the behaviour, and whether any container was stopped or deleted.
